# KrakvaMCL

Just a Minecraft Launcher.

Releases - https://github.com/Krakva1337/KrakvaMCL/releases/

**KrakvaMCL** is a modern **Minecraft launcher** built with **Node.js**.  
The project focuses on simplicity, modern design, and open-source development.

---

# 🇬🇧 English

## About

**KrakvaMCL** is an open-source Minecraft launcher written in **Node.js**.

The goal of the project is to create a **lightweight, modern, and customizable launcher** that can be easily modified by developers and used comfortably by players.

## Features

- ⚡ Built with **Node.js**
- 🎨 **Modern UI design**
- 🔓 **Open-source**
- 🧩 Easy to modify and extend
- 🚀 Lightweight and fast
- 🛠 Developer-friendly structure

## Open Source

KrakvaMCL is completely **open-source**, meaning anyone can:

- explore the source code
- contribute improvements
- create forks
- build their own launcher based on this project

## Development

Requirements:

- Node.js
- npm or yarn

Install dependencies:

```bash
npm install
```

Run the launcher:

```bash
npm start
```
